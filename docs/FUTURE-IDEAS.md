# Future Feature Ideas

Ideas collected during development for potential future implementation.

## ~~Mid-Session Exercise Swap~~ (Implemented)

Basic mid-session swap is now available via the swap button on each exercise header.
Future enhancements:
- Log the swap reason for pattern detection
- Track swap frequency per exercise for insights

## Superset Tracking

Support pairing two exercises as a superset within a workout.
- Timer that accounts for both exercises in the pair
- Rest period only after completing both exercises
- Volume tracking that understands superset context

## Per-Set Weight Pyramiding

Allow different weights across sets for the same exercise (e.g., 20kg, 22.5kg, 25kg).
- Current system assumes same weight across all sets
- Pyramid up (ascending) and pyramid down (descending) patterns
- Display average and peak weight in history
